# Stardew Valley — узелки, календарь и справочник

Офлайн-справочник по Stardew Valley: 30 узелков общинного центра, календарь дней рождения и праздников, вики по предметам, рецептам, NPC, гайдам и каталогам. Один самодостаточный HTML-файл: все картинки встроены, внешних запросов нет.

**Сайт:** https://hedplay.github.io/stardew-bundles/

## Файлы

| Файл | Назначение |
| --- | --- |
| `index.html` | Сам сайт (основной файл, его и редактируем) |
| `stardew-bundles.html` | Маленькая заглушка-редирект на `index.html` для старых ссылок |
| `publish.cmd` | Публикация обновлений на GitHub Pages |
| `.gitattributes` | Запрет на автопреобразование переводов строк (файл должен попадать на сайт байт в байт) |

## Как обновить сайт

1. Отредактируйте `index.html`.
2. Дважды щёлкните `publish.cmd` (или выполните `git add -A`, `git commit -m "..."`, `git push`).
3. Изменения появятся на сайте обычно через 1–2 минуты. GitHub Pages кэширует страницы до ~10 минут, поэтому если изменений не видно — обновите страницу с `Ctrl+F5` и подождите.

Проверить, что всё отправилось: `git status` и `git log --oneline -5`.

## Локальный просмотр

Просто откройте `index.html` в браузере — сайт полностью офлайн, интернет не нужен. Прогресс узелков хранится в `localStorage` браузера (`sv-bundles-v1`), поэтому у локальной копии и у сайта он независимый.

## Хостинг

GitHub Pages, ветка `main`, корень репозитория. Репозиторий публичный — это требование бесплатного тарифа GitHub для Pages.
